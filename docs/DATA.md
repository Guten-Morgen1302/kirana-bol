# Data, licences and consent

The contest rule: use synthetic data. No real phone numbers, account numbers, Aadhaar, PAN or recorded calls.

## What data this project uses

- **Orders** (`data/orders.json`): 30 invented grocery orders. No real customers or shops.
- **Catalog and prices** (`catalog.json`): invented items and invented prices in rupees.
- **Clean speech**: either Gnani Timbre TTS output (synthetic voice) or your own voice reading the invented orders. Mark which one you used when you publish results.
- **Noise**: built-in beds are generated by `lib/noise.js` from a seeded random generator. They are not recordings and carry no third-party licence. If you add a real bed, record it below.
- **Transcripts** from the demo server are not stored or logged.

## If you record your own voice

- Read only the invented `say` text. Do not say real names, numbers or addresses.
- If you record another person (a friend, a relative), get their permission **in writing** (a chat message is enough) before publishing their clips, and note it below. Prefer not to commit other people's voices; keep those clips local.

## Fill in before publishing

- Speech source for the published table: `TTS (Timbre)` / `my voice` / `other` -> ________
- Noise bed: `synthetic street` / `synthetic shop` / `file: ______ (source, licence)` -> ________
- Other speakers and their consent: ________
- Timbre output terms: check the Gnani terms page before redistributing TTS audio in a public repo. The repo git-ignores `data/clean/` and `data/mixed/` by default for this reason.

## Secrets

The Gnani API key lives only in `.env` (git-ignored). Rotate it after the contest (dashboard -> API keys). The test suite scans the repo for key-shaped strings.
