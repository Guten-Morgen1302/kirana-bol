# Kirana Bol demo video

Motion graphics in [Remotion](https://www.remotion.dev) (React), 1920x1080, 30 fps, 2:09. Style reused from a previous demo video: dark background, one orange accent, Bricolage Grotesque + JetBrains Mono, spring animations.

## What is real, what is animated

- **Every number** comes from the result files in the repo root (`results.json`, `results.v3.json`, `results.human.v2.json`, `results.human.v3.json`); they are copied into `src/data.ts`.
- **Failure cards** are verbatim transcripts from those files.
- **Footage scenes** (live mic order + readback, then two of my own recordings uploaded) are the unedited screen recording, only sped up (1.6x and 2.1x) and cropped to remove the browser tab strip and bookmarks (personal tabs). Nothing is blurred or altered. The uploads are my own voice as recorded, with no added noise; they are not the simulated 10 dB / 0 dB clips.
- Waveforms, the pipeline diagram and the bar charts are animations, labelled as such. Noise levels are labelled SIMULATED everywhere.

## Rebuild

```bash
cd video
npm install

# 1. (optional but recommended) cut your screen recording into the two footage scenes
bash cut_clips.sh ../recordings/pending.mkv   # 0:00-0:23 live, 0:24-0:53 upload; crop via CROP=w:h:x:y

# 2. voice-over: Gemini TTS, voice Fenrir, one wav per scene -> out/vo/NN.wav + timing.json
#    needs GEMINI_API_KEY in ../.env (never commit it) and: pip install google-genai python-dotenv
python make_vo.py            # all lines; or: python make_vo.py 8 9
python make_vo.py --check    # transcribes every wav so you can compare it with the script

# 3. render + synthesized music + ducked mix + loudness trim -> out/kirana-bol.mp4
bash render_all.sh

# thumbnail
npx remotion still src/index.ts Thumbnail out/thumbnail.png
# preview and scrub
npx remotion studio src/index.ts
```

Scene lengths live in `src/Root.tsx`. The two footage scenes are 14 s each; `cut_clips.sh` stretches your cut to exactly that, so scene length always equals clip length. If you change a scene length, change the matching line start times in `make_vo.py` (scene starts are listed in a comment above `LINES`).

## The recording used

`recordings/pending.mkv` (1280x720, 58 s, git-ignored): live mic order and readback (0:00-0:23), then two uploads of my own mp3 recordings (0:24-0:53). The top 116 px (tabs, bookmarks) are cropped away; the file picker shows only folder names and file names.

## Layout

| File | Purpose |
|---|---|
| `src/Root.tsx` | scene list and the two compositions (Main, Thumbnail) |
| `src/scenes.tsx` | all 12 scenes |
| `src/ui.tsx` | shared components (browser frame, kinetic type, code typing, tabs) |
| `src/data.ts` | real numbers copied from the result files |
| `src/theme.ts` | colours, fonts, FPS |
| `src/clips.ts` | generated by `cut_clips.sh`: which clips exist |
| `cut_clips.sh`, `make_music.sh`, `make_vo.py`, `mix_audio.py`, `render_all.sh` | media pipeline |

The music is synthesized with ffmpeg `aevalsrc` (no samples, no licence issues). The voice is Gemini TTS; check Google's terms for your use.
